# (parantez)

Genç okurlar için günlük bülten girişimi — konsept web sitesi.

Saf HTML/CSS/JS, build adımı yok. `index.html` dosyasını tarayıcıda açman yeterli.

- `index.html` — sayfa
- `styles.css` — İsviçre tarzı editoryal grid, açık tema
- `script.js` — içindekiler menüsü, abonelik formu (konsept, veri göndermez)

İçerikler ve görseller (picsum.photos) placeholder'dır.
