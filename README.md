# (parantez)

Genç okurlar için günlük bülten girişimi — konsept web sitesi.

Saf HTML/CSS/JS, build adımı yok. `index.html` dosyasını tarayıcıda açman yeterli.

- `index.html` — sayfa
- `styles.css` — brütalist, açık tema
- `script.js` — tarih, "okundu" takibi, abonelik formu (konsept, veri göndermez)

İsim ve içerikler placeholder'dır.
